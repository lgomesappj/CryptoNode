# CryptoNode

CryptoNode enables high-performance, asynchronous processing through secure peer-to-peer communication within a decentralized network protocol.

CryptoNode is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoNode.git`
2. `cd CryptoNode`
3. Install in editable mode: `pip install -e .`

## Configuration

CryptoNode is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
